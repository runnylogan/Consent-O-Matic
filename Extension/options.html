Backup & restore

Custom rules are snapshotted inside the extension on every change (last 10), and can also be pushed to a GitHub repository, one commit per change, so the repository history is your dated backup trail. The push writes backup.json (rules and settings, for restoring) and custom-rules.json (rules only, usable as a rule-list URL). Rule names include site hostnames, so use a private repository. The token needs Contents: read and write on that one repository and is kept only in this browser profile.

Rule-list gist (optional)

Gives you a rule-list URL other browsers can use. The token needs the Gists account permission (write), which covers all your gists, so keep it separate from the repository token.
