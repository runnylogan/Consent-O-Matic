Your custom rules

Rules for banners the downloaded lists don't cover: ones this extension generated or you taught it, plus the ones that shipped with it. They are checked first. Deleting one also keeps it out of future backups.

    Downloaded rule lists

    [[RULES_DESCRIPTION]] They refresh automatically every 22–48 hours.

    Back up to GitHub

    Each change to your custom rules is saved as a commit in a private repository, so its history is your dated backup trail (rule names include site hostnames). The token needs Contents: read and write on that one repository and stays in this browser profile only.

    Restore

    For a new install or after a mistake. Your rules are also snapshotted inside the extension on every change (last 10).

    A file can be a backup made here or a plain rules .json file.
